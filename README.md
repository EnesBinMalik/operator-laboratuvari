# Operatör Laboratuvarı

![Operatör Laboratuvarı — rozet](docs/rozet.svg)

> **C# · nesne yönelimli temeller** — tasarım ve geliştirme: **Enes Öztürk**

---

Enes Öztürk tarafından hazırlanan Türkçe programlama operatörleri ve karar yapıları eğitim uygulaması.

## Öne çıkanlar

- Sınıf, metot ve erişim belirleyicileri
- Değişken, operatör ve veri tipleri
- Kapsülleme ve kurucu metot örnekleri
- Arayüzde adım adım kod anlatımı

## Kurulum ve çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
```

| Komut | Not |
| --- | --- |
| `npm install` | bağımlılıklar |
| `npm run dev` | geliştirme sunucusu |
| `npm run build` | üretim derlemesi |
